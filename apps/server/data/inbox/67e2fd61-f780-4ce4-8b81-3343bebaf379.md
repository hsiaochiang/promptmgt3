---

/ui/

**順序**
1. 先把雛形完整搬到 `src/App.jsx`，確保畫面一致。

### `.specify/memory/constitution.md`（可直接貼上）

```md
# Prompt Manager UI Constitution (v3)

## 0. 目的與範圍
本文件定義「專案與提示詞管理工具」之前端 UI/UX 準則與資訊架構，作為 SpecKit / Coding Agent 實作時的唯一對照依據。
UI 以 Notion 風格為參考：左側導覽、主區列表/看板、右側抽屜式詳細頁（Side Panel）。

參考原型：ui_prototype_v3.jsx（Vite + React + Tailwind + lucide-react）。


## 1. 全域版面（Layout）
### 1.1 左側 Sidebar（固定）
分區：
- Projects
  - 專案列表
  - 專案看板
- Prompts
  - 提示詞列表
  - 提示詞看板
- Tools
  - 剪貼簿
  - 設定（目前尚未實作）

規則：
- Sidebar 可收合/展開；收合時僅顯示 icon。
- 目前所屬頁面需高亮標示。

### 1.2 主內容區（Main Content）
依 Sidebar 選擇顯示：
- projects：ProjectSection
- prompts：PromptSection
- clipboard：ClipboardView
- settings：顯示「設定頁面尚未實作」（暫時 placeholder）

### 1.3 右側詳細頁（Side Panel，Notion-style）
- 點擊任何 Project / Prompt / Snippet（剪貼簿項目）後，開啟右側抽屜。
- 背後主畫面以半透明遮罩覆蓋；點遮罩可關閉。
- 抽屜可「展開/縮回」為更寬的閱讀/編輯模式。
- 抽屜內可進行欄位編輯（部分欄位 change 即存）、內容編輯區塊、關聯資料導覽（例如：提示詞可跳回所屬專案）。


## 2. 資訊架構（IA）與頁面定義
### 2.1 專案管理
#### (P1) 專案列表頁
目的：以表格/樹狀層級呈現專案，支援搜尋、切換「列表/看板/已封存」、新增。
必要元素：
- 頁首標題：專案管理
- View Tabs：列表 / 看板 / 已封存
- 搜尋（右側）
- 主 CTA：+ 新增（右側）

表格欄位（至少）：
- 名稱（可展開顯示該專案的提示詞清單）
- 狀態（規劃中/進行中/暫停/完成）
- 優先級（high/medium/low 或等價）
- 標籤（chips）
- 更新（日期）

互動：
- 點專案或其下提示詞：開啟右側 Side Panel。

#### (P2) 專案看板頁
目的：以狀態分欄（規劃中/進行中/暫停/完成）呈現專案卡片。
卡片資訊：
- 專案名稱
- 專案簡述（1~2 行）
- 標籤 chips
- 更新日期（右下）

互動：
- 點卡片：開 Side Panel。


#### (P3) 專案編輯頁（Side Panel）
專案欄位（Properties）：
- 狀態：planned / in_progress / paused / done
- 專案類型：對外簡報 / 內部工具 / 客戶專案 / 教學課程 / 個人研究 / 其他
- 平台標籤、交付物標籤、受眾標籤、共通標籤（以 chips 增加）
- 更新時間（日期）

內容區：
- 專案描述（多行）
- 檔案列表（可新增檔名，暫以文字模擬 Upload）
- 關聯提示詞列表（列出屬於此專案的提示詞）


### 2.2 提示詞管理
#### (R1) 提示詞列表頁
目的：以表格列出所有提示詞，支援依專案顯示、搜尋、切換「列表/看板/已封存」、新增。
必要元素：
- 頁首標題：提示詞管理
- View Tabs：列表 / 看板 / 已封存
- 搜尋（右側）
- 主 CTA：+ 新增（右側）

表格欄位（至少）：
- 名稱
- 所屬專案
- 狀態（草稿/待優化/可用/停用）
- 優先級
- 標籤
- 更新（日期）

#### (R2) 提示詞看板頁
目的：以狀態分欄（草稿/待優化/可用/停用）呈現提示詞卡片。
卡片資訊：
- 提示詞名稱
- 所屬專案
- 標籤 chips

互動：
- 點卡片：開 Side Panel。

#### (R3) 提示詞編輯頁（Side Panel）
提示詞欄位（Properties）：
- 狀態：draft / needs_review / ready / deprecated
- 專案：可下拉選擇專案；顯示為可點擊的藍色連結樣式
- 模型：GPT-4o / GPT-4 Turbo / Claude 3.5 Sonnet / Claude 3 Opus / Gemini 1.5 Pro / Gemini 1.5 Flash（可擴充）
- 連結：文字輸入（例如貼入 ChatGPT/Gemini 對話連結）
- 標籤 chips
- 更新時間（日期）

內容區（Markdown 類文字）：
- 備註（多行）
- 內容編輯（以段落區塊呈現：任務、限制、輸出格式等）


### 2.3 剪貼簿（Snippets）
#### (C1) 剪貼簿頁
目的：管理「角色設定 / 格式要求 / 限制條件 / 風格指令 / 未分類」等片語，並提供「最近使用」快速複製。
必要元素：
- 頁首標題：剪貼簿與常用片語
- 左側：分類瀏覽清單（可新增分類）
- 右側：最近使用卡片（至少 3 張）
- 每張卡片包含：標題、分類標籤、內容區塊、Copy 操作（複製後提示）

互動：
- 點卡片：開 Side Panel（可在抽屜內編輯內容）

#### (C2) 片語編輯頁（Side Panel）
欄位：
- 標題
- 分類
- 內容（多行文本）
操作：
- Copy（複製到剪貼簿）
- Save（依原型可為自動保存或顯式保存）


### 2.4 設定
目前為 placeholder：顯示「設定頁面尚未實作」。


## 3. UI/互動準則（必遵）
1) 每頁 Header 右側只保留一個主 CTA（新增/儲存/上傳）。
2) 列表/看板切換以 Tabs 呈現，並保留「已封存」入口。
3) 點選項目優先以 Side Panel 編輯，不跳整頁（降低切換成本）。
4) 所有日期顯示使用 YYYY-MM-DD。
5) 標籤以 chips 呈現；新增行為以「+ Add」或同等小 CTA。
6) 設計一致性以 ui_prototype_v3.jsx 與截圖為準；若實作結果與原型差異，需先修正 UI 再進功能。
```
