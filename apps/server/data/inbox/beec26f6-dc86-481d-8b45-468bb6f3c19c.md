# Excel 下拉選單設定

**Created**: 01/08/2026 17:39:11

## User

excel的儲存格 如何插入下拉選單

## AI

以下為 **Microsoft Excel** 中在儲存格插入「下拉選單（資料驗證清單）」的標準作法，適用於向客戶或主管說明。

---

## 一、使用「資料驗證」建立下拉選單（最常用）

image_group{"query":["Excel 資料驗證 下拉選單","Excel Data Validation dropdown list","Excel 資料驗證 清單 設定"]}

### 操作步驟
1. **選取目標儲存格**  
   點選欲插入下拉選單的儲存格（例如：A1）。

2. **開啟資料驗證功能**  
   功能區 →【資料】→【資料驗證】→【資料驗證】。

3. **設定允許類型**  
   在「設定」分頁中：  
   - 【允許】：選擇 **清單（List）**  
   - 勾選「儲存格內下拉式清單」

4. **輸入選項來源（Source）**  
   依需求擇一：
   - **直接輸入文字**：  
     例如：  
     ```
     高,中,低
     ```
   - **指定儲存格範圍**（推薦）：  
     例如：  
     ```
     =$D$1:$D$5
     ```

5. **確認完成**  
   點擊【確定】，儲存格即出現下拉箭頭。

---

## 二、以「指定儲存格範圍」管理選項（實務建議）

image_group{"query":["Excel 下拉選單 來源 範圍","Excel dropdown list source range","Excel 資料驗證 範圍"]}

### 建議做法
- 將選項集中放在一個隱藏或輔助工作表（如「Settings」）
- 方便後續維護與調整，不需重設每個下拉選單

**範例**
```
Settings!A1:A4
啟用
停用
待確認
已完成
```

在資料驗證「來源」填入：
```
=Settings!$A$1:$A$4
```

## 三、進階設定（實務常見需求）

### 1️⃣ 限制只能選下拉內容  
- 預設即為限制，避免使用者任意輸入文字。

### 2️⃣ 顯示提示訊息（Input Message）  
- 可在「輸入訊息」分頁設定操作說明，例如：  
  >「請選擇案件狀態」

### 3️⃣ 錯誤警示（Error Alert）  
- 當輸入非清單內容時顯示提示，提升資料一致性。

---

## 四、常見問題補充

- **Q：可否多選？**  
  Excel 原生下拉選單 **不支援多選**，需搭配 VBA 或 Office Script。

- **Q：可否依前一欄位動態改變？**  
  可，需使用 **命名範圍 + INDIRECT()**（屬進階用法）。
