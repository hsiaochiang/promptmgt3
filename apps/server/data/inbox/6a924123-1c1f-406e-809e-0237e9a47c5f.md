# 一、Power Platform（以治理先行）＋ CoE Starter Kit 是什麼？

## 1. Power Platform 的本質定位（給資訊主管的說法）

**Microsoft Power Platform** 是一套「**由資訊單位可治理的低程式／自動化平台**」，設計目的不是讓使用者隨意開發，而是：

> 在 **IT 可控、可稽核、可回收** 的前提下，  
> 讓業務與服務單位能快速完成「非核心、流程型、長尾需求」。

核心組成包含：
- **Power Apps**：快速建立內部應用程式（Web / Mobile）
- **Power Automate**：流程自動化（含雲端流程與 RPA）
- **Power BI**：分析與報表
- **Copilot Studio**：對話式助理（可選）

資料來源：Microsoft 官方產品說明 citeturn1search0

---

## 2. CoE Starter Kit 是什麼？為什麼對銀行關鍵？

**CoE Starter Kit（Center of Excellence）不是開發工具，而是「治理工具組」**。

它解決的是銀行資訊主管最在意的問題：

| 資訊主管的痛點 | CoE 能做的事 |
|---|---|
| 不知道誰做了哪些 App / Flow | 自動盤點所有資產 |
| 不知道哪些流程在跑、跑多頻繁 | 使用量、執行次數、失敗率監控 |
| 擔心 Shadow IT | 建立核准流程與環境隔離 |
| 離職、異動風險 | 可回收、轉移資產 |
| 無法對稽核交代 | 產出治理與使用報告 |

**一句話給主管：**
> CoE Starter Kit 是讓 Power Platform「不失控」的管理後台。

資料來源：Microsoft 官方 CoE Starter Kit 說明文件 citeturn1search1
