# High-Level Goal
提供一個「就地整理」工具，讓使用者在編輯器中以最少步驟完成暫存內容的貼標籤、命名、歸檔與整理，並確保主系統能即時反映檔案搬移與屬性更新。

# User Stories
## 歸檔與更新屬性
- As a 使用者, I want to 在編輯器中把暫存項目歸檔到指定專案與分類位置, So that 我能在寫作/整理時不必切換回主介面。
- As a 使用者, I want to 一次完成標題、狀態、優先級、標籤與歸檔位置更新, So that 我能降低零碎操作成本。
- As a 使用者, I want to 在執行前看到變更預覽, So that 我能確認不會搬錯地方或改錯資訊。

## 協助建議（可插拔）
- As a 使用者, I want to 取得建議的標籤/狀態/優先級/命名與目的地, So that 我能更快完成初次分類。
- As a 使用者, I want to 能接受或微調建議後再套用, So that 我仍保有控制權。

## 一致性與安全
- As a 使用者, I want to 任何變更都符合既定命名與屬性規則, So that 資產庫結構長期可維護。
- As a 使用者, I want to 支援撤銷（至少一次）或提供可回復策略, So that 我能降低誤操作風險。
- As a 使用者, I want to 在衝突情境（同名/不存在/格式錯誤）得到清楚指引, So that 我能快速排除問題。

# Domain Models
## ArchivePlan
- 來源項目（暫存或提示詞）
- 目標專案
- 目標路徑
- 新檔名
- 欲更新的屬性（標題、狀態、優先級、標籤、來源連結、備註）
- 衝突處理策略（改名/覆蓋/中止）

## Suggestion
- 建議標題
- 建議標籤（含分類）
- 建議狀態與優先級
- 建議目的地與命名
- 理由（可選）

# Workflows
## A) 暫存項目歸檔
1. 使用者選取暫存項目。
2. 工具產生歸檔計畫預覽（目的地、檔名、屬性變更）。
3. 使用者確認後執行：更新屬性、搬移檔案、必要時改名。
4. 主系統即時反映檔案變更。

## B) 建議後套用（可插拔）
1. 使用者觸發「產生建議」。
2. 使用者接受/調整建議。
3. 工具套用建議並完成歸檔。

# Predefined Data
- 預設命名規則：由標題生成可讀檔名（去除非法字元）
- 衝突策略：自動加尾碼或提示使用者選擇
