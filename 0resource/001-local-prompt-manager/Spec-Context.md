# High-Level Goal
打造一套「以檔案為核心」的提示詞資產管理主系統，讓使用者能在同一處完成專案/提示詞的整理、撰寫、分類、搜尋、封存，以及可追溯的版本備份與歷史檢視；同時保留與外部工具整合的標準入口，支援未來擴充匯入與歸檔流程。

# User Stories
## 導航與視圖
- As a 使用者, I want to 透過側邊欄在專案/提示詞/工具/設定間快速切換, So that 我能用固定路徑完成日常操作。
- As a 使用者, I want to 在「列表」與「看板」之間切換, So that 我能用不同視角管理進度與優先順序。
- As a 使用者, I want to 看到外部修改後的即時同步更新, So that 我不需要手動重新整理畫面就能掌握變更。

## 專案管理
- As a 使用者, I want to 新增、編輯、封存、刪除專案, So that 我能維持專案結構清晰且可整理歷史資料。
- As a 使用者, I want to 為專案設定摘要、標籤與關聯檔案, So that 我能保留脈絡與參考資料。

## 提示詞管理
- As a 使用者, I want to 新增、編輯、封存、刪除提示詞, So that 我能管理提示詞生命週期並區分可用與待整理項目。
- As a 使用者, I want to 為提示詞設定狀態、優先級、標籤、備註、來源連結, So that 我能快速判斷用途與成熟度。

## 編輯體驗（正文 + 中繼資料）
- As a 使用者, I want to 在同一個頁面編輯「正文」與「中繼資料區塊」, So that 提示詞內容與屬性可以同步維護。
- As a 使用者, I want to 在停止輸入後自動保存, So that 我不需要頻繁手動存檔也不會遺失內容。
- As a 使用者, I want to 拖曳圖片/附件到編輯區後自動整理並插入引用, So that 我能快速補齊示例與素材連結。

## 剪貼簿與常用片語
- As a 使用者, I want to 透過片語浮層一鍵插入常用指令模組, So that 我能用模組化片語快速組裝提示詞。
- As a 使用者, I want to 以分類與最近使用排序管理片語, So that 我能在最少操作下完成插入。

## 暫存區（Inbox，Web MVP 只做檢視與簡修）
- As a 使用者, I want to 檢視尚未歸檔的匯入內容, So that 我能先集中收集再安排整理。
- As a 使用者, I want to 對暫存項目做最小幅度編修（標題/刪減/註記）, So that 我能在歸檔前完成必要清理。
- As a 使用者, I want to 明確知道「歸檔」由外部工具處理, So that 我理解流程分工且不會誤解功能缺漏。

## 搜尋與快速定位
- As a 使用者, I want to 搜尋標題、標籤與全文內容, So that 我能快速定位資產並降低重複撰寫。
- As a 使用者, I want to 透過狀態、優先級、標籤快速篩選, So that 我能建立自己的工作視角（例如只看待優化/高優先級）。

## 版本備份與歷史
- As a 使用者, I want to 在重要事件後建立可回溯節點, So that 我能追溯關鍵變更而不被瑣碎編輯淹沒。
- As a 使用者, I want to 每日自動建立一次快照, So that 我能有穩定的日常備份節奏。
- As a 使用者, I want to 一鍵觸發立即備份, So that 我能在大整理後確保資料安全。
- As a 使用者, I want to 查看該資產的歷史列表並可開啟舊版內容, So that 我能理解演進並在需要時回復。

## 設定與治理
- As a 使用者, I want to 設定資料根目錄與附件目錄, So that 我能把資產放在我習慣管理與同步的位置。
- As a 使用者, I want to 管理全域標籤（新增、改名、刪除、合併）與分類, So that 標籤體系能持續演進且保持一致。
- As a 使用者, I want to 自訂常用選項清單（例如模型/來源）, So that 資料描述可符合我的實際工作環境。
- As a 使用者, I want to 檢視備份狀態與設定, So that 我知道資料是否安全與可推送。

# Workflows
## A) 專案與提示詞管理
1. 使用者建立專案並設定屬性。
2. 使用者在專案下建立提示詞並設定狀態、優先級、標籤與正文。
3. 使用者可切換列表/看板視圖管理資產。
4. 使用者可封存/還原資產，以維持現役列表乾淨。

## B) 提示詞編輯（正文 + 中繼資料 + 自動保存）
1. 使用者開啟提示詞詳細頁。
2. 使用者編輯正文與中繼資料。
3. 系統在停止輸入後自動保存並更新更新時間。

## C) 附件拖曳與引用
1. 使用者拖曳圖片/附件進入編輯區。
2. 系統將附件整理至附件目錄並在正文插入引用。

## D) 片語插入
1. 使用者開啟片語浮層。
2. 使用者點擊片語，一鍵插入到游標位置並更新最近使用排序。

## E) 暫存區（Inbox）檢視與簡修（MVP 不含歸檔）
1. 使用者在暫存區查看新匯入項目。
2. 使用者可做標題/刪減/註記等簡修。
3. 系統提供清楚提示：歸檔流程由外部工具處理。

## F) 搜尋與篩選
1. 使用者輸入關鍵字或套用篩選條件。
2. 系統回傳符合的專案/提示詞/暫存項目（含摘要片段與標籤）。
3. 使用者點擊結果直接開啟詳細頁。

## G) 版本備份與歷史檢視
1. 在重要事件後建立版本節點。
2. 每日自動建立一次快照。
3. 使用者可查看歷史列表並開啟舊版內容（進階）。

## H) 外部變更同步
1. 系統偵測資料根目錄發生新增/修改/搬移/刪除。
2. 主介面即時更新側邊欄、列表/看板與詳細頁顯示。

# Predefined Data
- 使用者角色：Owner
- 專案狀態：規劃中、進行中、暫停、完成
- 提示詞狀態：草稿、待優化、可用、停用
- 標籤分類：平台標籤、交付物標籤、受眾標籤、共通標籤
- 片語分類：角色設定、格式要求、限制條件、風格指令、未分類
