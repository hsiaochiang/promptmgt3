# High-Level Goal
提供一個「一鍵收集對話」工具，讓使用者能將瀏覽器中的對話內容快速轉為可整理的暫存項目，送進主系統的暫存區，降低靈感流失與複製貼上的摩擦。

# User Stories
## 一鍵匯入
- As a 使用者, I want to 在對話頁面一鍵匯入目前對話, So that 我能把可復用內容立刻收進暫存區。
- As a 使用者, I want to 匯入時自動帶入來源資訊（平台、連結、匯入時間、標題）, So that 我能保留可追溯性與脈絡。
- As a 使用者, I want to 在匯入成功/失敗時收到清楚提示與重試方式, So that 我能確信資料是否已被保存。

## 匯入品質
- As a 使用者, I want to 匯入內容維持段落結構、角色區分與程式區塊可讀性, So that 後續整理不需要大幅返工。
- As a 使用者, I want to 在匯入前能刪減敏感段落（可選）, So that 我能降低保存敏感內容的風險。

## 安全與授權
- As a 使用者, I want to 只允許匯入到我授權的位置, So that 匯入不會送往未知目的地。
- As a 使用者, I want to 可隨時撤銷授權並停用匯入, So that 我能控制資料流向。

# Domain Models
## ImportSource
- 平台名稱
- 對話頁連結
- 匯入時間
- 匯入範圍（整段/選取）
- 匯入狀態（成功/失敗/待重試）

## ImportedConversation
- 標題（可自動產生）
- 訊息序列（角色、內容）
- 原始格式保留資訊（清單、引用、程式區塊）
- 附註（可選）

## InboxItem
- 標題
- 來源平台
- 來源連結
- 匯入時間
- 原始內容
- 清理狀態（未處理）

# Workflows
## A) 一鍵匯入到暫存區
1. 使用者在對話頁觸發匯入。
2. 工具擷取並整理對話內容。
3. 工具附加來源資訊後送入暫存區。
4. 使用者收到成功提示；失敗則顯示原因與重試。

## B) 匯入前刪減（可選）
1. 使用者預覽擷取內容。
2. 使用者刪減敏感段落後送出。

# Predefined Data
- 支援平台：ChatGPT、Gemini（可擴充）
- 匯入狀態：成功、失敗、待重試
- 清理狀態：未處理
