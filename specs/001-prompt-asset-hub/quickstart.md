# quickstart.md — 檔案為核心的提示詞資產管理主系統

## 先決條件
- Node.js 20 LTS、npm
- 已設定資料根目錄與附件目錄的讀寫權限

## 安裝與啟動
```bash
npm install
npm run dev:server   # 啟動本機 Fastify 伺服器
npm run dev:web      # 啟動前端 Vite 開發伺服器
```

## 基本設定
1. 於設定頁輸入資料根目錄、附件目錄。
2. 儲存後後端將驗證讀寫權限，失敗會提示並阻擋寫入。

## 核心流程驗證
- **自動保存**：在提示詞詳情編輯正文/中繼資料，停止輸入 ≤2s 後應顯示保存成功，重新整理內容一致。
- **附件拖曳**：拖曳檔案到編輯區，附件應落盤至附件目錄並在正文插入引用連結（檔名採 UUID + 副檔名）。
- **搜尋/篩選**：建立多筆資產後，以關鍵字/標籤搜尋（預設只搜 Project/Prompt 且 `archived=false`；不含 Inbox/Trash），結果 95% 需 <1s。
- **暫存區簡修**：新增暫存項，修改標題/備註後保存；UI 顯示「歸檔由外部工具處理」。
	- **暫存項刪除**：刪除 InboxItem 為永久刪除（不進回收站），需確認並有成功/失敗回饋。
- **已封存（Archive）**：封存專案/提示詞後，於 Tools → 已封存 同頁檢視封存專案 + 封存提示詞，並可用類型篩選切換。
- **剪貼簿（Clipboard/Snippets）**：於 Tools → 剪貼簿 新增片段、編輯內容，並可一鍵複製到系統剪貼簿。
- **版本/快照**：觸發立即備份或建立版本節點，確認快照含附件複本且歷史列表可開啟。
- **回收站（刪除/復原/永久刪除）**：
	- 刪除提示詞/專案後，應出現在 Sidebar 的「回收站」視圖
	- 復原時若目的地衝突，必須提示選擇「覆蓋 / 改名 / 取消」且不得靜默覆蓋
	- 永久刪除需明確確認；刪除/復原後列表與索引需立即更新

## 回收站保留天數（Retention）
- 於設定頁調整 `trashRetentionDays`（預設 30 天）。
- 驗證到期清理失敗時需可觀測並可重試（不得部分刪除造成不一致）。
