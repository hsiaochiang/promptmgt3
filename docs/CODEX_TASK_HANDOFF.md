# Codex Task Handoff（交付任務模板）

目標：你不需要懂程式，只要把「問題 + 期望 + 驗收點」講清楚，我就能直接改、你就能直接驗收。

---

## UI/UX 任務模板（推薦）

```
頁面/位置：
  （例：Sidebar -> 提示詞列表）

你遇到的問題：
  （例：列表太擠、按鈕不明顯、對比太低）

你希望變成：
  （例：更像 Notion；row hover 顯示操作；欄位對齊一致）

參考：
  （例：0resource/notionstyle/01 專案和提示詞列表.png）

完成標準（驗收點）：
  - （例）我用肉眼就能判斷「有/沒有做到」
  - （例）不需要改資料結構，只改 UI 呈現
```

---

## Bug 任務模板（你只要貼錯誤即可）

```
操作步驟：
  1) ...
  2) ...

預期結果：
  ...

實際結果：
  ...

錯誤訊息/截圖：
  （直接貼上）
```

---

## 建議的任務粒度

- 一次只改 1 個頁面的 1 個區塊（例：Project List 的 row 樣式與欄位對齊）
- 每次改完都可手動驗收，必要時再補 e2e 保護（Playwright / Vitest）
